# Mistress's Mystery Wheel

Upload `index.html` to the root of a GitHub repository. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`.

- 8 fixed colourful segments with hidden prize names.
- Only the prize landed on is revealed after each spin.
- 3 unique results per round; at least one is sushi or donuts.
- Results saved in browser localStorage across refreshes.
- Play Again resets the current round after three spins.
- This is a playful page-only lock, not a device lock or secure secrecy. Source code is publicly visible on GitHub Pages.

Edit the `prizes` array in `index.html` to change the rewards.
